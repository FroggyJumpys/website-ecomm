## Summary

The static template has been moved to `legacy-template/` and the repository is now an npm
workspace with `client/` (React 19 + Vite 8 + Tailwind 4) and `server/` (Express 5 + `pg`). Root
scripts, ESLint flat config, Prettier, `.gitignore`, a Postgres compose file, an env example, a
health-check endpoint with tests, and a rewritten README are in place. `npm install`, `npm run
lint`, `npm run build`, `npm test` and a live proxy smoke test all pass on this machine.

## Decisions and trade-offs

- **npm workspaces instead of two independent installs.** One `npm install`, one lockfile, and
  `npm run dev` can start both processes. Cost: hoisted `node_modules`, so a stray dependency
  import can resolve without being declared. ESLint's `no-undef` (via `globals`) catches most of
  that early.
- **Tailwind 4 CSS-first config.** No `tailwind.config.js` and no PostCSS. Design tokens will be
  declared in `@theme` in step 02.
- **API always behind `/api`, in dev via the Vite proxy.** The session cookie stays first-party,
  which keeps `SameSite=Lax` viable and avoids CORS-with-credentials problems later. CORS is still
  configured on the server for direct calls and non-proxy setups.
- **`/health` never touches the database.** A liveness probe that fails because Postgres is down
  makes local debugging confusing; readiness lives at `/health/db`.
- **Express 5 conventions.** Async handlers rely on v5's automatic rejection forwarding instead of
  `express-async-errors`. Also means no `"*"` route patterns (path-to-regexp v8), so the 404
  handler is a plain `app.use`.
- **`helmet()` with default settings.** Fine for a JSON API; step 06 revisits CSP once the client
  is served from the same origin.
- **`client` test script uses `--passWithNoTests`.** The client has no tests until step 07, and a
  red `npm test` on a clean checkout would violate the definition of done. This flag is removed in
  step 07.
- **Node `>=22.12`** rather than `>=22` because Vite 8 refuses older 22.x minors.

## Out of scope / noticed

- `legacy-template/public/pages/*.html` reference `../../node_modules/@fortawesome/...` and
  `flowbite`, which are no longer installed. The folder is reference-only and is never served, so
  the broken links are intentional; do not "fix" them.
- `legacy-template/public/pages/ondex.js` is a stray 4-line Flowbite import from the original
  template. Kept in `legacy-template/` untouched for fidelity.
- npm 11 blocked `bcrypt`'s `node-gyp-build` install script, but the package still loads and hashes
  correctly (`$2b$10$...`) because the prebuilt binary ships in the package. If a teammate hits a
  `MODULE_NOT_FOUND` for `bcrypt`, run `npm approve-scripts bcrypt` or switch to `bcryptjs`.
- npm warns that `eslint@9.39.5` is "no longer supported" upstream. It is still the newest 9.x and
  the newest release that `eslint-plugin-react` accepts (see 01a).
